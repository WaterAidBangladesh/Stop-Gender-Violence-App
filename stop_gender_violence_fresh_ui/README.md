# stop_gender_violence_ui (UI only)

This archive contains the **lib/**, **assets/**, and **pubspec.yaml** for the UI. It is ready to be dropped into a fresh Flutter project or used to generate platform folders.

Instructions:
1. Unzip this folder to a directory.
2. From the project root run (Windows: use setup.bat, mac/linux: use setup.sh):
   - `flutter create .`
   - `flutter pub get`
3. Then run:
   - `flutter run`

This will create `android/`, `ios/`, etc. with the correct v2 Android embedding so you won't see the old-embedding error.
